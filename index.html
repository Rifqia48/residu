Investigasi 1 • 12 Menit

Mengenal Residu pada Garis A

Gambarlah diagram pencar dan Garis A: ŷ = 2 + 0,4x di buku tulismu. Setiap anggota menghitung nilai prediksi (ŷ) dan residu (e = y − ŷ) untuk satu tahun.

Ide Konsep: Residu (e) adalah jarak vertikal antara nilai data sebenarnya (y) dan nilai prediksi pada garis (ŷ). Ingat urutannya jangan terbalik: Data Asli dikurangi Prediksi (e = y − ŷ).
Langkah Hitung:
1. Substitusikan nilai x ke persamaan Garis A: ŷ = 2 + 0,4x.
2. Hitung e = y − ŷ.
3. Jika e > 0 (positif), titik data berada di atas garis. Jika e < 0 (negatif), titik data berada di bawah garis.
Contoh Serupa: Misalkan terdapat titik (x = 5 ; y = 3,5) pada garis ŷ = 2 + 0,4x:
• Prediksi ŷ = 2 + 0,4(5) = 2 + 2 = 4,0
• Residu e = y − ŷ = 3,5 − 4,0 = −0,5 (karena negatif, titik berada di bawah garis).

Investigasi 2 • 13 Menit

Membandingkan Garis dengan Kuadrat Residu (Σe²)

Bagilah kembali tugas menghitung residu untuk Garis B (ŷ = 1,5 + 0,5x) dan Garis C (ŷ = 3,9 + 0,3x), lalu selidiki mengapa Σe saja bisa menipu!

Ide Konsep: Residu positif (di atas garis) dan residu negatif (di bawah garis) dapat saling meniadakan saat dijumlahkan biasa (Σe mendekati nol meskipun garisnya melenceng jauh). Agar semua residu bernilai positif, kita mengkuadratkan tiap residu (e²) lalu menjumlahkannya (Σe²).
Langkah Kerja:
1. Hitung residu e = y − ŷ untuk Garis B dan Garis C pada titik tahun bagianmu.
2. Kuadratkan masing-masing residu (e²) kemudian jumlahkan untuk keempat tahun (Σe²).
3. Garis yang paling pas (best fit) di antara ketiganya adalah garis dengan jumlah kuadrat residu (Σe²) terkecil.
Contoh Serupa: Misalkan pada suatu titik diperoleh residu e = −1,20, maka e² = (−1,20)² = +1,44 (ingat: bilangan negatif dikuadratkan hasilnya selalu positif!). Jumlahkan keempat nilai e² untuk memperoleh Σe².

Investigasi 3 • 15 Menit

Menemukan Persamaan Garis Regresi Linear (ŷ = a + bx)

Setelah memilih garis terbaik di antara A, B, dan C pada Investigasi 2, adakah garis lain dengan jumlah kuadrat residu (Σe2) yang lebih kecil lagi? Mari temukan Garis Regresi Linear!

Rumus Garis Regresi Linear (ŷ = a + bx):
b = Σ(x − x)(y − y) Σ(x − x)2
a = y − b · x
Cara Menghitung Rata-Rata:
• Jumlahkan keempat nilai x lalu bagi 4: x = (x2018 + x2019 + x2020 + x2021) ÷ 4
• Jumlahkan keempat nilai y lalu bagi 4: y = (y2018 + y2019 + y2020 + y2021) ÷ 4
Urutan Kolom di Buku Tulis: Buatlah tabel dengan kolom (x − x), (y − y), hasil kali (x − x)(y − y), dan kuadrat (x − x)2. Hati-hati: negatif dikali negatif hasilnya positif!
Contoh Serupa (Misalkan titik x = 4,0 ; y = 3,0 dengan x = 5,5 dan y = 4,2):
• x − x = 4,0 − 5,5 = −1,50
• y − y = 3,0 − 4,2 = −1,20
• (x − x)(y − y) = (−1,50) × (−1,20) = 1,80
• (x − x)2 = (−1,50)² = 2,25
